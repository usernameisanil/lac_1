# Unit 4: Multivariable Differentiation and Optimization

## Topics

### 1. Differential Calculus of Several Variables
- Functions of several variables, limits and continuity
- Partial derivatives and higher-order partial derivatives
- Total derivative and chain rule

### 2. Differential Geometry & Fields
- Gradient, tangent plane and normal line
- Divergence and curl

### 3. Functional Dependence & Approximations
- Jacobians and functional dependence
- Taylor expansion of two-variable functions

### 4. Optimization
- Maxima and minima
- Second derivative test
- Lagrange multipliers and constrained optimization

## Python / AI Integration
- 2D/3D Gradient field visualization using Matplotlib
- Symbolic computation and verification of Jacobians using SymPy
- Constrained optimization routines using the SciPy optimize module
- Interactive scripts/plots to interpret saddle points, extrema, and optimization constraints
